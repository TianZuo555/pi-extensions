Bridge global pi skills as one `pi__p<pid>__activate_skill` tool whose JSON-schema enum is the catalog and whose description carries each skill's one-liner, preserving pi's progressive disclosure. Bridge mode no longer appends `## pi Agent Skills` to the user prompt — tools/list is rebuilt on every agy spawn, including after compaction. When the bridge is disabled or fails to register with agy, the direct-mode path catalog is used as a fallback so skills are never silently invisible.
