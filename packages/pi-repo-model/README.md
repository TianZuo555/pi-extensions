# pi-tian-repo-model

Per-repository default model and thinking-level preferences for [pi](https://pi.dev).

```bash
pi install npm:pi-tian-repo-model
```

Provides `/repo-model`, `/repo-model-unset`, and `/repo-model-list`. An explicit `pi --model ...` takes precedence over the repo default on startup.

See the [collection repository](https://github.com/TianZuo555/pi-tian-extensions#pi-repo-model) for full documentation.
